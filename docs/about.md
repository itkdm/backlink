# 关于布吉岛外链导航

布吉岛外链导航帮助产品团队寻找可以提交产品链接的平台。我们收录的平台都必须提供产品链接提交或发布入口，不是供用户使用的 SaaS 或 AI 工具清单。

可收录的产品形态包括网站、APP、插件和桌面软件。每个平台接受的类型和准入条件不同，提交前请先查看对应的平台说明。

## 信息来源与核实

平台资料以其官网的投稿页面、收录规则、帮助中心和定价页面为依据。详情页提供官网、投稿入口及可确认的费用、提交要求、登录和外链信息；暂时无法从官方资料确认的字段不展示。平台规则可能变化，页面中的核实日期仅表示我们最近一次检查信息的时间。

Domain Rating（DR）来自 Ahrefs，用于描述域名指标，不代表平台质量、收录概率或提交后的 SEO 效果。平台拥有最终审核与收录决定权；提交入口的展示不构成收录、流量或排名保证。
