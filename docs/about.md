# 关于本站

布吉岛外链导航专门整理可提交产品链接的平台，帮助出海 SaaS、AI 工具和互联网产品找到目录收录与发布入口。这里收录的是“可以提交你的产品的网站”，不是供你使用的 SaaS 或 AI 工具清单。

## 收录原则

- 收录提供产品提交、目录上架或产品发布流程的平台。
- 优先链接到平台的实际提交入口，并按 SaaS 目录、AI 工具目录、发布社区等场景分类。
- 提交审核、费用、收录结果以及外链属性由各平台决定，本站不保证一定收录或带来 SEO 效果。
- 平台规则可能变化；提交前请查看目标平台的最新要求。

本站当前提供中文与英文页面，后续会继续补充并复核提交平台。
