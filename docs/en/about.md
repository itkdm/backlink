# About this directory

Bujidao Link Directory curates useful websites, tools, and internet products across SEO and growth, AI and development, web products, design, and analytics. It aims to make finding resources clearer and faster.

## Editorial policy

- We prioritize official websites and project pages with a clear purpose and ongoing maintenance.
- Links are grouped by practical use, with a short description to help readers decide what to explore.
- Inclusion does not imply a partnership or endorsement. External websites are operated by their respective teams.
- Links are reviewed periodically and updated when information changes.

The directory currently supports Chinese and English. Additional languages and categories can be added using the same content structure.
