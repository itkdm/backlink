# About this directory

Bujidao Backlink Directory lists platforms where you can submit product links. It helps global SaaS, AI tools, and internet products find directory listing and launch pages. This is a directory of places to submit your product, not a catalog of SaaS or AI tools to use.

## Editorial policy

- We list platforms that provide product submission, directory listing, or launch flows.
- We link to the actual submission page when available and group sites by use, such as SaaS directories, AI tool directories, and launch communities.
- Each platform controls its review, fees, acceptance, and link attributes. We do not guarantee a listing or SEO results.
- Platform policies can change; check the current requirements before submitting.

The directory currently supports Chinese and English. We will continue adding and reviewing submission platforms.
